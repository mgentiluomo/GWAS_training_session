# PLINK executable

Step 0.6 puts the PLINK 2 program here. Run `source("R/plink_setup.R"); prepare_course_plink()`
in R. It copies `plink2.exe` (Windows) or `plink2` (macOS/Linux) from the project package.
You can also download PLINK 2 from <https://www.cog-genomics.org/plink/2.0/> and copy only
the PLINK 2 executable here. Executables are intentionally not stored in Git.
See [setup](../docs/setup.md).
