# Original training notebooks

These original materials are preserved for comparison and advanced exercises.
For the revised three-session course, start at [course home](../README.md) and
use `lessons/`.

The older notebooks use a different folder layout and both PLINK 1.9 and PLINK 2.
Their generated HTML reflects an earlier version. They are not interchangeable
with the guided workflow, which uses shared configuration, explicit ID joins,
clean-session restarts and separate demo/class outputs.
