## Phase 4. Association on the dosages (section A.9)

Script `assoc_l4.sh`. The same model as the main analysis (step 6.3): `--covar covar.tsv --covar-name
Age,PC1-PC10 --covar-variance-standardize --glm sex hide-covar firth-fallback`, `--maf 0.01`. Covariates and
PCs from `sim2026_moduleA/work/verify/covar.tsv` (the file `verify_sim2026.py` builds for 6.3).

Working command on the dosages (Git Bash; on Windows use `bin\plink2.exe`):

```sh
bin/plink2 --vcf chr18.dose.vcf.gz dosage=DS --double-id --extract-if-info "R2 >= 0.3" \
  --update-sex s5-7_state.psam col-num=3 --pheno s5-7_state.psam --pheno-name Disease \
  --maf 0.01 --covar s6-2_covariates.tsv --covar-name Age,PC1-PC10 --covar-variance-standardize \
  --glm sex hide-covar firth-fallback cols=+a1freq,+machr2 --out s_A9_chr18
```

Syntax notes, all tested:

- `dosage=DS` reads the Minimac4 dosage; without it PLINK uses the hard calls in GT.
- `--extract-if-info "R2 >= 0.3"` filters on the Minimac INFO field R2 (the quotes are needed).
- `--double-id`: the VCF has only the IID; the course covariate file has FID = IID, so the FID must be set to
  the IID for the rows to match. All 11 covariates were loaded for all 1,811 samples.
- Sex and the phenotype are not in a VCF: `--update-sex <psam> col-num=3` and `--pheno <psam> --pheno-name
  Disease`. 900 cases and 911 controls.
- `cols=+machr2` adds the MaCH r2 computed by PLINK from the dosages, a check of the R2 of the INFO field.

8,334 imputed variants passed R2 at least 0.3 and MAF at least 0.01 (chr18 region).

**Does L4 emerge after imputation?**

| Analysis | Variant | Frequency | R2 | OR | p-value |
| --- | --- | --- | --- | --- | --- |
| Array sites, main model | best: `18:38107932:C:A` (65 kb from L4) | 0.255 | typed | 1.49 | 6.6e-7 |
| Imputed dosages | causal `chr18:38042715:G:A` | 0.283 | 0.940 | 1.47 | 1.65e-6 |
| Imputed dosages | best: `chr18:38106879:G:C` | 0.406 | 0.814 | 1.54 | 4.2e-8 |
| True genotypes (instructor) | causal `chr18:38042715:G:A` | 0.288 | 1 | 1.46 | 1.31e-6 |
| True genotypes (instructor) | best: `chr18:38116132:A:G` | 0.374 | 1 | 1.46 | 1.6e-7 |

Reading: the causal variant is imputed well (R2 0.94) and its result is almost the same as with its true
genotype (p 1.65e-6 against 1.31e-6). It is not the top of the region: correlated variants 50 to 80 kb away
give smaller p-values, as often in real data. After imputation the best variant reaches p = 4.2e-8, just
below 5e-8, while with true genotypes the region does not go below 1.6e-7. So the "genome-wide significant"
result after imputation is partly noise in the dosages of a variant with R2 0.81. This is a good teaching
case: an imputed hit needs its R2, a look at the array signal and, ideally, confirmation by direct
genotyping. The array alone gives 6.6e-7 at the best site.
